# External link brand marks

GitHubBrand/mark.svg is an unmodified GitHub Invertocat Black vector from https://brand.github.com/GitHub_Logos.zip, used to identify the project link. Brand guidance: https://brand.github.com/foundations/logo.

XBrand/mark.svg is the unmodified logo.svg from the X brand toolkit download, used to identify the developer profile link. Source: https://about.x.com/en/who-we-are/brand-toolkit (x-logo.zip).

These are third-party trademarks, not SwiftRust logos or an added icon library. The marks remain subject to their respective owners' brand/trademark rules; the project does not relicense them under AGPL or imply endorsement. Rendered as a monochrome template to maintain contrast in light/dark appearance.
